# 开发日志：液态玻璃渲染方案演进（2026-08）

记录玻璃着色器从「物理仿真」到「物理启发的 authored 模型」的完整演进，
包括每一次翻车的原因与教训。对应代码：`src/engine/glass/shaders.ts`。

## 0. 结论速览

| 维度 | 最初方案 | 当前方案 |
|------|----------|----------|
| 折射 | 双界面物理折射：顶面折射 → 光线追踪至底面（Newton 迭代求交）→ 再折射出射 → 投影到背景平面 | 构造性单调偏移场：主体透镜 + 边带弯折，共享一个 C² 权重交接 |
| 偏移方向 | SDF 梯度 ∇d | q³ 超椭圆解析方向场 |
| 偏移幅度权重 | 边带内 pow 曲线 | 宽过渡带（2.2× 倒角）上的 smootherstep |
| 距离场 | 原始 SDF（硬 min/max） | 精确 SDF（mask/阴影）+ smax 平滑 SDF（所有权重）双轨 |
| 亮度/反射 | Schlick Fresnel × Studio 柔光箱 + 肩部光泽环 | authored 径向亮晕（直接写出剖面）+ 线性 env 色彩 + 抛光发丝线 |
| 设计不变量 | 「贴近物理」 | **单调（不折叠）、无中轴线、C² 连续、防折叠预算**——由构造保证，不靠调参 |
| 内反射重影 | 有（后删除：镜像采样=倒像） | 无 |

## 1. 最初方案：物理仿真路线

v0.2 初版的思路是「把真实厚玻璃算出来」：

1. 穹顶高度场 `z = h(p)`（中心即有曲率），上下双界面；
2. 每像素在顶面用 Snell 折射，光线行进到底面——底面位置用 **Newton 迭代**
   在高度场上求交；
3. 底面再次折射出射，射线投影到虚拟背景平面采样场景纹理；
4. 每通道独立 IOR → 全身色散；光程 Beer-Lambert 吸收；奶白散射；
5. 内部反射重影、Studio 柔光箱环境、Fresnel 权重。

这套方案的每一环在物理上都对，但在 **UI 玻璃的约束下逐环崩塌**。

### 为什么物理路线失败（五个层面）

1. **物理目标与产品目标互斥**。真实厚玻璃边缘的折射偏移沿半径呈钟形
   （中心 0 → 峰值 → 轮廓回落），钟形映射必然非单调：一段背景被采样
   两次（倒像）、相邻内容被跳过（错位）——真实水滴边缘的倒像正是它。
   物理上正确，但 UI 玻璃要求背后内容连续、可读、只出现一份。
   这不是取舍问题，是互斥问题，物理框架内无解。

2. **参数域错配**。物理公式是在厘米级玻璃上被"校准"出丰富视觉的，
   缩到 18px 的 UI 玻片后所有高阶效应的信号都缩没了：Fresnel
   `(1−cosθ)⁵` 要法线转到 60°–90° 才抬升，UI 坡面倾角封顶 ~20°，
   F 恒等于 f0 ≈ 4%（动态范围为零，乘任何 ramp 都是乘常数）；
   Beer-Lambert 在 18px 光程下衰减 0.2%，不可见；双次折射在薄玻片上
   几乎共线。公式是对的，但在这个参数域里它们是**存在但不可见的死项**
   ——亮度断层修了几轮无效，就是因为一直在调一个数值上是常数的项。

3. **物理模型没有 UI 需要的不变量**。采样映射单调、轮廓边界干净、
   滑条连续变化，这三条 UI 硬约束在物理框架里没有对应旋钮——它只保证
   「光线算对了」，不保证「结果适合做 UI」。每次违例只能事后打补丁，
   补丁之间还会互相打架。当前方案把不变量做成构造约束，由结构保证。

4. **链条越长误差越相乘**。双折射 + Newton 迭代 + 投影是一条乘法链：
   Newton 在高度场梯度突变处（SDF 中轴线）收敛变差、交点跳动 → 折射场
   裂缝；任何一环的近似都被后续环节放大。症状（错位/倒影/断层）离病因
   （某一环的数学性质）隔了三层抽象，每轮修复都在猜。

5. **「像玻璃」是感知特征问题，不是辐射度问题**。人眼识别玻璃只靠
   少数特征：边缘弯折位移、轮廓亮线、高光形状、色散镶边、运动视差。
   物理渲染追求辐射度正确，而参考图（Yaan 海报）本身是 art-directed
   的——柔光箱位置、边缘亮度都是摆出来的风格化强调。要像那张图，
   正确做法是直接 authored 这些特征的剖面。

正确的分层：**不变量用数学构造保证，感知特征直接 authored，
物理公式退居为参数语义**（ior/thickness/dispersion/absorption 仍在，
调起来符合直觉）。

## 2. 崩塌点一：钟形剖面 → 镜像折叠

**现象**：边缘折射出「两个镜像的 F」——背景文字在边带内倒像。

**根源**：光滑穹顶的物理折射偏移沿半径是**钟形**（中心 0 → 边缘峰值 →
轮廓处回落）。钟形意味着采样映射 `x_screen → x_scene` 非单调：一段背景
被采样两次（镜像），相邻内容被跳过（错位）。这是真实水滴边缘倒像的
成因——物理正确，但 UI 玻璃必须显示**一份连续内容**。

**修复**：放弃物理求交，改为**构造性单调偏移场**——

```
offset = lens·(1−S) + bend·S        （S 为共享权重，径向单调递增）
```

透镜项（向内，小放大）平滑交接给弯折项（向外，边缘位移），两项各自
沿半径单调，合成映射恒单调 → 数学上不可能折叠。

**教训**：*物理正确 ≠ 产品正确。* 真实玻璃的折叠/倒像是特性，
UI 玻璃的折叠是缺陷。选择「author the profile, keep the knobs」。

## 3. 崩塌点二：SDF 梯度的 medial axis

**现象**：玻璃呈「棱锥/棱面」，V 形折痕，长边中点尤甚。

**根源**：偏移方向取自 SDF 梯度 ∇d，而 `d = min(a−|x|, b−|y|)` 的梯度
在**中轴线**（横边/竖边最近邻切换处）方向跳变。

**修复**：方向场换成解析**超椭圆（n=4）法线场** `normalize(q³)`，
任意点光滑。

**埋下的债**：只换了**方向场**，**幅度场**（offT 等）仍从原始 d 派生。
中轴线问题只修了一半 → 第 5 节的漫长返工。

## 4. 亮度断层的连环误诊

**现象**：中心与边带之间亮度过渡有肉眼可见的台阶，多轮修复无效。

**误诊链**（按时间）：

1. 以为中心太暗、边缘太亮 → 调 env 灰底、透镜项 —— 无效；
   用户纠正：*「灰色就是透射的背景颜色」*，中心纯透是正确的。
2. 认为过渡带被锁在 52px 边带 → 加全局 spread ramp 乘 Fresnel —— **零效果**。
   数值尸检发现原因：**Schlick Fresnel 在浅坡面上是死的**——UI 玻璃坡面
   倾角 < 20°，`(1−cosθ)⁵` 永远抬不起来，F 全窗恒等于 f0 ≈ 0.0375，
   任何乘在 F 上的 ramp 都是在乘常数。
3. 真正的可见亮环是 **shoulder 光泽环**：门控在 52px 边带内的
   `smoothstep(0.3,0.7)→(0.72,1.0)` 环，+22% 峰值、宽 20px、非单调——
   那才是断层本体。它与 Fresnel / curvature / spread 全都无关，
   所以之前调什么都纹丝不动。

**修复**：反射亮度改为 **authored 径向亮晕**——直接写出剖面
`gloss = pow(1−bodyT, 1.2 + 0.5·curvature)`，跨整个内半径单调连续，
curvature（顶部平坦度滑条）控制亮晕宽窄；删除 shoulder、rim、Fresnel
权重路径与 env 灰底。

**教训**：*先给每个 term 算数值贡献，再动手改。*「物理项存在」不等于
「物理项可见」——Fresnel 在这个定义域里贡献 0.6% 亮度，
改它等于没改。

## 5. 四条 45° 棱线：还第 3 节的债

**现象**：从四个角沿 45° 方向伸出四条棱线，字母在棱线两侧「跳跃」。

**定位过程**（关键：用户的对照实验）：

- 「棱线明显度随边缘透镜滑条变化，折射幅度滑条只影响两侧内容差异」
  → 棱线驱动项同时乘 lensMag 与 bendAmp，而 bendAmp 被 clamp 钳死
  （sceneDistance > 238 后不再变化）——观测与代码逐项吻合；
- 「四条线、45°、从四角出发」→ 正是 SDF `min(a−|x|, b−|y|)` 的
  **角平分线中轴线**，斜穿整个激活带。棱线住在**幅度场**里，
  而第 3 节只修了方向场。

**两次失败的修法**：

1. 全部权重迁移到超椭圆半径 `rad = (|qx|⁴+|qy|⁴)^¼` —— **白角回归**：
   rad 不是边界保真的，角落处达 2^¼ ≈ 1.19，`edgeT ≥ 1` 的区域在四角
   楔形饱和 → 轮廓光全开 → 白色楔块。
2. 自造 smooth-min 距离组装 —— **全窗回归**：把「内缩矩形的 SDF」
   （内部为负）误当「到圆弧的正距离」参与 min → 中心距离 = −210 →
   edgeT 全窗饱和 → 整窗纯白。

**最终修法**：不组装任何新距离，在**原始 SDF 公式内部**把导致梯度
翻转的那一个 `max(q.x, q.y)` 替换为 C² smooth-max：

```wgsl
fn smax(a, b, k) {            // |a−b| > k 时严格等于 max
  h = smoothstep(0, 1, 0.5 + 0.5·(a−b)/k);
  return mix(b, a, h) + k·h·(1−h);
}
sdSmooth = length(max(q,0)) + min(smax(q.x, q.y, 12), 0) − r;
```

边界保真（轮廓处处为 0）、px 带宽不变、与精确 SDF 偏差 ≤ k/4
（3px，表现为沿角平分线一条平滑的浅谷）、角平分线翻转被摊成
~8px 的 C² 过渡。**改完在中心/边界/边内 s px/角落 45°/角平分线
五个点位手工验算后才提交。**

## 6. 边缘过亮：遮蔽层的撤退

追棱线期间为了「遮蔽轮廓跳位」不断向边缘堆亮（rim 0.36 + 抛光芯
0.5 + gloss env 0.4 ≈ +1.3）→ 根源修好后这些遮蔽层全部过量，
边缘糊成白边。按最终配平收回：

| 项 | 峰值过量 | 最终 |
|----|----------|------|
| gloss 环境反射 | 0.42（cap 0.55） | 0.26（cap 0.38） |
| 轮廓亮线 | pow³·0.36 | pow^3.5·0.18 |
| 抛光芯 | pow⁹·0.5 | pow^12·0.22（~3px 发丝线） |

轮廓处的物理跳位（折射位移 vs 窗外原位）保留：**无跳位 ⟺ 有镜像**，
二者数学上互斥（让偏移在轮廓归零 = 负斜率 = 折叠），跳位由发丝线
密封，这是 Apple 液态玻璃同款取舍。

## 7. 当前方案全景

```
距离场（双轨）
  ├─ 精确 sdRoundBox ──────→ 轮廓 mask、阴影（需要精确几何）
  └─ sdRoundBoxSmooth ─────→ 窄边带 edgeT、宽偏移带 offT、
                             gloss/高度场 bodyT（需要光滑）

折射偏移（构造性单调场）
  ├─ 方向：dirOut = normalize(q³)          （超椭圆，无中轴线）
  ├─ 幅度：lens·(1−S) + bend·dirOut·S      （共享 C² smootherstep）
  ├─ 带宽：offBand = min(2.2×bevel, 0.55×inR)
  └─ 防折叠预算：bendAmp ≤ offBand·0.45 − lensMag·|halfSize|
       （峰值采样斜率 = 1.875·(bendAmp+lensMag·|p|)/offBand < 1，
        连透镜贡献一起记账，任何滑条组合都不会折叠）

亮度（authored）
  ├─ 径向亮晕：pow(1−bodyT, 1.2+0.5·curvature) × env（线性冷暖 tilt）
  ├─ 轮廓亮线 pow(edgeT,3.5)·0.18 + 抛光发丝线 pow(edgeT,12)·0.22
  └─ 紧致 spec 点（pow 瓣，无膝点）
  （env 无 smoothstep 膝点：amplified 法线会扫过整个可达域，
   任何被扫过的膝点都会印出一条等值亮线）

其他
  ├─ 高度场：双段式（smoothstep 基底的主体穹顶 + 倒角环），
  │  只供光照/吸收，折射不再触碰曲面
  ├─ 透镜与 curvature 解耦：curvature 只塑造高光，不放大内容
  └─ 内容贴膜无视差：clamp UV，内容稳定不随折射漂移
```

## 8. 哲学转变与方法教训

**从「仿真物理」到「物理启发的 authored 模型」**：保留物理参数旋钮
（ior、thickness、dispersion、absorption、milkiness、curvature），
但在物理无法交付 UI 所需性质的地方（Fresnel 响应、单调映射、
过渡带宽）直接书写剖面，并把**数学不变量作为构造约束**：
单调、无中轴线、C² 连续、防折叠预算——由结构保证，不靠调参维持。

方法教训：

1. **改之前先算每个 term 的数值贡献**——本轮最大的时间浪费都在
   修改「存在但不可见」的项（Fresnel × spread = 乘常数）。
2. **用户对照实验是最强的定位工具**——「滑条 A 影响明显度、滑条 B
   只影响两侧内容」这类二值观测直接把嫌疑从折射路径切到光照/距离场。
3. **半修是债**——修 medial axis 时只修方向场不修幅度场，债在
   滑条极端值下重新显形，返工三轮。
4. **换坐标要验边界保真**——超椭圆半径在角落 overshoot 到 2^¼，
   白角回归；自造距离组装搞混符号约定，全窗惨白。新距离函数
   必须在关键点位数值验算后再上。
5. **遮蔽性 hack 要随根源修复撤退**——为掩盖 bug 加的亮边/补偿层，
   在 bug 修死后要主动收回，否则变成新的「太白太亮」。
